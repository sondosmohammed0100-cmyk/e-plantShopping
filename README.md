
# e-plantShopping 🌿

## Project Description
e-plantShopping is a React-based shopping cart application for an online plant store.  
Users can browse houseplants, add items to a shopping cart, update quantities, and view total cost dynamically.

## Features
- Browse houseplants by category
- Add items to shopping cart
- Increase / decrease quantity
- Remove items from cart
- Dynamic cart total calculation

## Tech Stack
- React
- Redux Toolkit
- JavaScript
- CSS
